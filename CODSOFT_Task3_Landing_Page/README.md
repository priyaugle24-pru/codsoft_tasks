# Nextora - Landing Page 

A responsive landing page built with only **HTML and CSS** (no JavaScript).

## Sections
Header with navigation + Log in / Sign up, Hero, Trusted-by logos, About Us, Services, Projects, Blog, Pricing, Call-to-action and Footer.

## Concepts used
- CSS Grid and Flexbox for columns and layout
- Sections, header and footer structure
- Consistent colour palette (teal, orange, navy) using CSS variables
- Hover effects and smooth scrolling
- Responsive design with media queries and a CSS-only mobile menu

## How to run
Open `index.html` in a browser.

## Files
- `index.html` - page structure
- `style.css` - all styling
