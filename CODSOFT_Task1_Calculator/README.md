# CODSOFT Task 1 - Calculator

A basic interactive calculator built using:
- HTML
- CSS
- JavaScript

## Features
- Addition, subtraction, multiplication and division
- Percentage/modulo operation
- Decimal numbers
- AC and DEL buttons
- Keyboard support
- Responsive calculator layout

## How to Run
1. Open `index.html` in a web browser.
2. Use the calculator buttons or your keyboard.
