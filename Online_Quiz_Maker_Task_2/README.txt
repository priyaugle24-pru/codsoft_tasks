# Online Quiz Maker — Level 2 Task 2

Open `index.html` in a browser.

Features:
- Home page with Create / Take Quiz options
- Quiz creation with multiple questions and 4 choices
- Correct-answer selection
- Quiz listing and search
- One-question-at-a-time quiz taking
- Immediate score + correct answer review
- Login / registration demo using browser localStorage
- Mobile responsive layout
- Quizzes persist in localStorage

Note: Authentication and quiz storage are front-end/localStorage demo functionality. A real production app would use a backend and database.
